## 机房分级：Evoxt 不按“CN2 GIA、9929”卖套餐

搜 VPS 推荐的人大多看过这套说法：AS4837 是联通普通线路，便宜、带宽足，晚高峰可能拥堵；AS9929 是联通精品，晚高峰稳得多；CN2 GIA 是电信高端线路，三网回程都能受益，价格也最贵；CMIN2 是移动精品，移动宽带访问延迟低。选线口诀是电信看 CN2 GIA、联通看 9929、移动看 CMIN2。

这套知识有用，但拿它来套 Evoxt 会落空。Evoxt 的套餐页按地区分级卖，不按线路标签卖，你看到的选项是“香港”“日本大阪”“日本东京”，不是“9929”“CMIN2”。这不代表机房线路差，而是意味着两件事：

第一，你没法从套餐名判断这台机器到你的运营商走什么路由。香港机房到国内 30–60ms 延迟是常态，延迟低和晚高峰不丢包是两回事，前者由物理距离决定，后者由线路和带宽收敛比决定。买之前最好找该机房的测试 IP 自己 ping 一遍晚高峰。

第二，地区分级会改变你的流量成本。香港和大阪属 Premium Network，超额流量 12 美元/TB；东京属 Standard，3 美元/TB。同样跑 2TB 月流量，大阪比东京多出的成本足够你再买一台 VM-0.5。

如果你的核心诉求是“国内三网晚高峰稳定”，并且希望线路标签写在明面上，那 Evoxt 不是为这个诉求设计的产品；它更适合对单核性能敏感、对价格敏感、对机房位置有明确要求的场景。

## 下单前的六个易错点

**优惠码在结账页填，不在选配页。** 部署流程走完、进入结账页面后找 Promotional Code 输入框，填进去点应用，金额立刻变。没变就是码失效，别反复试。

**退款条款要自己确认。** 官网定价页和购买页没有单独列出退款期限，也没有写“多少天内无理由”。下单前在服务条款页或结账页确认清楚，别默认有几天冷静期。作为参照，同类的 DigitalVirt 写明正价商品流量不超过 10G 可全额退款、用优惠码购买的不支持退款；ZgoCloud 写明特价套餐不支持退款。Evoxt 是不是同类规则，得你自己在条款里看到才算数。

**流量超额是自动计费的。** Standard 3 美元/TB、Premium 12 美元/TB、Premium Plus 24 美元/TB。跑视频、做下载、挂图床的，先把月流量算清楚再选机房。

**备份是每周一次，不是实时。** 所有套餐自带免费的每周异地备份，这对付误删和机房故障够用，但对数据库这类需要按小时恢复的业务不够，重要数据自己做快照或外部备份。

**换 IP 的政策没写在定价页上。** 额外 IPv4 是 3 美元/月，但已有 IP 更换是否收费、收多少，官网定价页没有说明。收到机器先测 IP 和路由，不满意尽早走退款流程。

**带宽是共享的。** 低价 VPS 的带宽基本都是共享，标称值不等于 24 小时都能跑满。这一点所有商家都一样，别只盯着带宽数字选。

## 常见问题

**月付还是年付？**

先月付。EVOXT595 是循环折扣，月付也能享受折后价，没有“必须年付才便宜”的门槛。跑一两个月，看晚高峰表现和资源占用，确认没问题再考虑拉长周期。Evoxt 支持最长 3 年的计费周期，也支持预充值让系统自动扣费，这两种方式都比一次性年付灵活。

**1 核 2GB 能装 Windows 吗？**

官网操作系统列表包含 Windows RDP，但 2GB 内存跑 Windows Server 余量很小。要用 Windows，从 VM-2 的 4GB 起，并确认授权方式和最低配置要求。

**香港和日本怎么选？**

两地都在亚太，延迟都比美国低。区别在分级：香港和大阪属 Premium Network，超额流量 12 美元/TB；东京属 Standard，超额流量 3 美元/TB。流量吃得多的选东京，需要香港出口位置的选香港。

**续费会不会涨价？**

按官网当前的定价结构，标价就是标价，没有“首期优惠价”和“续费价”两套数字。用码的情况下，如果码是循环的，续费同价；码失效了，你按标价续费，标价本身不变。商家保留调价权利。

**跑分和实际体验差多少？**

官网主打的是单核频率，最高标到 6.0 GHz+。这类机器在 PHP、Node、Python 这类单线程响应敏感的应用上表现好，在多线程渲染、大规模并行计算上不吃香。买之前想清楚你的负载是单线程还是多线程。
